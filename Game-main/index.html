🎮 Game Rules

⏰ Basic Rules

  • Timer Mode: 🔥 3 seconds per move
  • Timeout Rule: If time runs out, the player loses the game immediately
  • Winning: Get 3 X's or O's in a row (horizontal, vertical, or diagonal)
  • Special Rule: Game continues if a swap or explosion happens during a winning turn
